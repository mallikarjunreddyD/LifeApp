backup compatibility, IndexedDB upgrade and offline expense entry, edit,
deletion and restore. Test Android input and offline reboot on Xiaomi Pad 7
and browser storage, narrow layout and keyboard on iPhone Safari and Windows.

offline replay, conflict review, exact chart totals, CSV/JSON export and
isolated PostgreSQL recovery with a disposable account. Production
