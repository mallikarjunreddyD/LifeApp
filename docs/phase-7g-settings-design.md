# Phase 7G.1 Settings

Settings opens to a protection summary and category links. Account & Security
holds sign-in, sign-out and connection review. Synchronization shows To-do
status and existing backup-verified first transfer and conflict controls.
Backup & Recovery contains the device's supported recovery actions. Android
also exposes Notifications. Appearance describes the current paper theme.

About LifeApp shows the app version. Expand Advanced diagnostics for the
origin, dataset and recovery epoch and the local checkpoint. These fields
remain in the synchronization protocol and are checked as before. The
alignment overlay is no longer reachable through Settings. The underlying
coordinate transforms and regression fixture are retained.

The Android local backup timestamp is written after destination read-back.
This is a local backup status. It carries no claim about Drive or PostgreSQL.
Server scheduling, automatic Drive backup and unified export are separate
Phase 7G milestones.
