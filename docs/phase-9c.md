# Phase 9C workouts and synchronization

Workouts has four sections on Android and the PWA. Use **Log → Add workout**
and select a saved routine to preload its exercises and planned sets. Tap an
exercise to edit its sets. **History** shows the latest ten workouts by date and
routine, with older workouts available through **Show all workouts**. Open a
workout, then an exercise, to see its recorded sets. **Routines** and **Exercises**
are the management screens. Archiving hides templates from future selection and
preserves history. Portable backup schema 12 preserves archived routines.

The PWA groups tasks due today separately and keeps successful automatic sync
quiet. Use the menu button to hide or show navigation. Settings retains
connection and sync controls.

Workout uploads, habit synchronization and To-do retain their existing account
scope. The PWA can continue checking other modules when To-do needs attention.
Android automatic Habits checks include existing non-overlapping months and
retain overlapping copies for review. Legacy handwriting upload copies stay
local. Clearing them is an explicit Settings action if they block new uploads.

For an existing connection that predates Workout or Habit support, open
**Settings → Synchronization**. On Android, use **Review synchronization** to
review and connect missing modules. In the browser, **Connect synchronization**
appears when a structured module still needs to be connected. Both flows use
the existing account and preserve local records for review when versions overlap.
