# Phase 9B LifeApp interface

Android and the PWA use the LifeApp name and an open-book checkmark on evergreen.
The Android launcher and PWA use the same artwork. Android notifications use
the monochrome book silhouette required by Android notification trays.

The tablet and desktop layouts put labeled navigation beside the workspace.
The browser uses a bottom bar on phones. On narrow Android screens, two rows
keep all destinations directly accessible. The same Compose theme applies to
all Android screens. The PWA keeps its light and dark palettes and bundles
Inter with its license for offline rendering.

On Android, verify navigation in both orientations, text scaling, access to
the expense editor and Settings, and pencil alignment near the edges of the
Journal, Planner and Notebook canvases. The app header reserves the same space
throughout a save. Verify the installed PWA icon, safe-area insets, text
scaling and keyboard on iPhone and desktop. Existing installations may refresh
their launcher or home-screen icon on the platform's own schedule.
